# DeepKnow RAG Assistant

## Overview
This project is a Retrieval-Augmented Generation (RAG) system focused on Deep Learning knowledge. It allows users to ask questions and receive answers based on a custom knowledge base built from domain-specific documents.

## Goal
To build an AI assistant that can answer questions from curated Deep Learning materials using LLMs + semantic search.

## Architecture
User Question → Embedding → Vector Search (FAISS) → Retrieval → Prompt Engineering → LLM → Response
